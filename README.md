# Interstellar Traveler

Relativity in OCaml, because why not?
Mostly just to learn basic OCaml syntax.

The epoch used is J2000.
Unfortunately, interstellar travel has not been developed yet,
at least not by humans (i.e., [*Homo sapiens*]).

If you are a member of an interstellar civilization that somehow speaks English,
feel free to use this program,
though I can not guarantee its accuracy
and am not liable for any costs or lost time incurred by miscalculated stellar coordinates.
You should probably use your more advanced spaceship navigation system.

If you are a human [software archeologist] in the far future,
in an era where interstellar travel has been invented,
perhaps you should use modern data from your own era,
not data from J2000.
